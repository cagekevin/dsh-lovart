## 1. 立项

- 2026-11-08 立项。独立仓库，**与 `lovart 自动`（Rust）零共享代码、零共享数据**。
- 目标：把 Lovart 免费排队出图接进 DSH 侧边栏和 agent。
- 上游协议事实来自对 `~/Documents/lovart 自动/src-tauri/src/lovart/*` 的逐行核对（2026-11-08 版本）。

## 2. 分期

| 期 | 交付 | 量 | 验收判据 |
|---|---|---|---|
| **P0** | `sign` + `request` + `api` + `prompt` + `download` + `phase` + `store` + `run` + 一条 `lovart_generate`（**立即返回 jobId，不等图**）+ 落盘 | 1.5 天 | 对 agent 说「画一只戴帽子的猫」，`lovart/` 里出现图；`job_output` 能读到文件路径 |
| **P1** | `/lovart/api` 路由 + 侧栏 tab：图墙 + 提交框 + 确认按钮 | 1.5 天 | 侧栏看到任务与缩略图；待确认任务能救回 |
| **P2** | 垫图、多模型下拉、重跑、图墙多任务 | 1 天 | 侧栏能上传参考图并随任务提交；模型/比例/尺寸从后端派生；历史任务可重跑 |

**P0 必须单独做，且不含任何前端代码。** 理由：协议没通之前，前端是调试负担不是资产。
P0 的验收方式是「对 agent 说一句话 + 看一个目录」，不点任何 UI。

合计 **4 天**。

> P0 之所以是 1.5 天而不是 1 天：它现在包含了 `phase` / `store` / `run` 三件 —— 原方案里
> 这些散在 P0 和 P1，合并后一次性做对，避免 P1 回头改 `lovart_generate` 的返回形状。

P2 之后的工作（排队、技能、多输入卡）见 [`02-排队与技能-2026-11-08.md`](02-排队与技能-2026-11-08.md)。

## 3. 验收清单

### 3.1 P0（无 UI）

1. 对 agent 说「画一只戴帽子的猫」→ 立即返回 `{jobs:[{id, phase:'submitting'}]}`
2. 会话头出现一行 `lovart-xxxx [lovart] running`，`progress` 从「提交中」→「排队中」→「生成中」
3. 图出来后 agent 收到 `background job … finished` 通知
4. agent 调 `job_output` 能读到文件绝对路径
5. `<cwd>/lovart/` 里文件名可读，重名不覆盖
6. 连提 6 个，第 5、6 个被拒并说明原因

> 第 6 条记录的是**当时**的行为（并发满直接拒）。排队方案落地后会改成「第 5、6 个进入等待」，
> 届时改 00 §5.6 并在此处补一行说明，不回头改历史结论。

### 3.2 P1（侧栏）

7. 侧栏出现 Lovart tab，未配凭据时显示「未配置凭据」而不是空白
8. 输入框提交 → 1 秒内列表出现新任务，缩略图随出图出现
9. 待确认任务显示「确认并继续（会扣积分）」，点一次后变「排队中」
10. 同一个任务第二次要确认 ⇒ 变失败并说明原因
11. 收起侧栏 3 分钟再展开，任务状态是最新的
12. DSH 重启后列表为空，`lovart/` 里的图还在
13. 点会话头那一行的停止按钮 ⇒ `LovartMeta.phase` 变 `cancelled`，侧栏同步更新

## 4. 选型：为什么挂 better-sidebar

先说结论：**画图墙的部分两边完全一样，都要自己写。** 差别在四周的脚手架。

| | better-sidebar | DSH 原生 |
|---|---|---|
| **拿到图片 URL** | `mediaUrl(scope, path)` —— 一个函数，传绝对路径返回可直接塞 `<img src>` 的地址 | 自己拼 `dsh-resource://file/session/<id>/<编码路径>`，要用 `@deepseek-ai/dsh-util-workspace-path` 的 `fileAddressFor` |
| **tab 条外观** | 进它自己那套 tab 条；`icon` 是任意 `ReactNode`，彩色也行 | 进 DSH 的 tab 条；`icon` 必须是 `ComponentType<IconProps>`，**单色跟随主题** |
| **点 `+` 的引导页** | `title` + `description` + `order` | 完整的 **guide 胶囊卡片**（图标 + 标题 + 说明 + 快捷键）—— 原生独有 |
| **右侧栏形态** | 继承原生（它就是装在原生侧栏上），**额外**多一个底部工作台 | `push` / `fullscreen`、窄屏自动全屏、分栏、浮窗、header 展开按钮、三组快捷键 |
| **布局持久化** | 它自己的 localStorage | `dsh.sidebar-right.v1.<sessionId>`，含分栏比例、浮窗矩形 |
| **tab 内容区** | 一块面板，随便画 | 一块面板，随便画 —— **一样** |

结论与理由已写进 00 §10.2（决定性只有一条：能拿到可直接塞 `<img src>` 的图片 URL）。

## 5. 开工前的验证门槛：没有

三条上游事实都已由 Rust 版证实，不需要先验：

| 事实 | 证据 |
|---|---|
| CDN 图裸 GET 可下载（无 Cookie / Referer） | `lovart 自动` 的 `download.rs` 就是裸 `client.get(url).send()`，全仓无 `Referer` |
| `pending_confirmation` 是**对象**不是布尔 | `task.rs` 有注释：「用 `as_bool()` 会漏判 ⇒ 确认闸门被绕过」 |
| `ratio` / `size` 拼进 prompt 文本，不是 API 参数 | `scheduler.rs` 的 `build_lovart_prompt` 调用 |
